# ポケスリ チーム編成ナビ

今週のカビゴンがリクエストしたカテゴリの中で、手持ちのメンバーが集める食材で
よくエナジーを稼げる料理とチームをさがすツールです。

### ▶ ここで使えます

**https://akirahaan-blip.github.io/pksl.teams/**

インストールも会員登録も要りません。スマホでもパソコンでも、このURLを開くだけです。

**入れたデータは、あなたの端末の中だけに保存されます。** どこかのサーバーに送られることは
ありません（通信は、文字のデザインと、スクリーンショット読み取りの部品を取りに行くときだけです）。

**この結果は試算です。** 料理の大成功のような**運の要素は平均でならして**計算しているので、
実際の数字は上にも下にもぶれます。**「これが唯一の正解」というものではありません。**
編成を考えるときの**ひとつの目安**として使ってください。

**この計算は「1日は1つの編成でとおす」前提です。**
実際には「カカオが2回ぶん集まったから蜜を集める子に替える」「料理パワーアップが発動したから抜く」
というように、**一日の中で都度入れかえるプレイングがほとんどだと思います。**
そういう立ち回りはここでは計算できないので、
**上手に回している人ほど、出る数字は実際より低くなります。**
（実例：1日の中で入れ替えている人の実測が3日で約201万だったのに対し、
ツールの試算はそれより低く出ました。設定を合わせても、この差は埋まりません）

合計の数字より、**「なぜこの料理か」（どの食材が何個足りないか・誰が出すか）**の方が、
入れ替えを考えるときの役に立つはずです。

計算に入れていないものは、下の「まだできないこと」にまとめてあります。

## 使い方

1. 上のURLをブラウザで開く
2. 画面の 1 → 2 → 3 → 4 を入れると、**5 に答えが出ます**

> パソコンにこのファイル一式を置いて使うこともできます。その場合は
> フォルダの中の **`サイトを開く.bat`** をダブルクリックしてください
> （`index.html` を直接ダブルクリックしても同じです）。

**ポケモンを自分で選ぶ必要はありません。** ボックスをまるごと読み込めば、
その中から一番エナジーを稼げる5匹と、何日目に誰を入れるかを自動で出します。
**ボタンを押す必要もありません**（設定を変えると自動で計算し直します）。

### 入れるもの

| 場所 | 何を入れるか |
|---|---|
| 1 行くフィールド | 今週いるフィールドを選ぶ＋**フィールドボーナス（％）** |
| 2 なべ | なべ容量・料理パワーアップの今の分・いいキャンプチケット |
| 3 料理カテゴリ | カテゴリ＋**レシピレベル**＋日曜＋イベント倍率＋**いま持っている食材** |
| 4 手持ちのポケモンを読み込む | 個体値チェッカーのCSVを貼り付けて「読み込む」 |
| **5 おすすめの編成** | **結果。**5匹・日割り・献立・合計エナジー |
| 6 自分で選んで試す | 開かなくてよい。中身の確認や、手で選んで比べたいとき用 |
| 6 の「くわしい設定」 | **睡眠スコア**（げんきの回復量が決まります） |

**ワカクサ本島だけ**、好みのきのみが毎週ランダムなので、自分で3つ選びます。

### なべ（鍋）について

「なべ容量」と「料理パワーアップで今ついている分」は、ゲームのホーム画面で
**なべ** をタップすると出る数字です。

なべに入れられる食材の数は、こう計算しています（出典: Wiki*「なべ」）。

```
（なべ容量 × 日曜2倍 ＋ 料理パワーアップ分）× いいキャンプチケット1.5倍 → 四捨五入
```

**日曜日はなべ容量が2倍**になります（ウィークエンドボーナス）。
例: なべ57 なら 平日57／日曜114、キャンプチケットありなら 平日86／日曜171。

**いいキャンプチケット**を「使っている」にすると、次の3つが計算に入ります。

- おてつだいスピードが **1.2倍**（＝おてつだいの間隔を 1.2 で割る）
- なべ容量が **1.5倍**
- ポケモンの**最大所持数が 1.2倍**（カバンがあふれにくくなります）

### 料理パワーアップ（ジバコイルなど）

手持ちに**料理パワーアップS**を持つポケモンを入れると、行に「スキルLv」欄が出ます。
結果の下に「**1日に何回発動して、なべがいくつ増える見込みか**」が出ます。

なべが足りなくて作れない料理は「**なべを広げれば作れる料理**」の表に出て、
「あと約○増やす（およそ○日ぶん）」まで表示されます。

なべに乗るのは「次の料理までにたまるぶん」です（上限 +200）。
計算はツールが自動でやるので、手で入れる必要はありません
（上の欄は、いまゲーム画面についている分を入れたいときだけ使います）。

スキルレベルごとの増加量は、料理パワーアップSが **+7 / 10 / 12 / 17 / 22 / 27 / 31**、
マイナス版が **+5 / 7 / 9 / 12 / 16 / 20 / 24** です（出典: pokesleep-tool の MainSkill.ts）。

### 個体値チェッカーから取り込む（おすすめ）

「4 手持ちのポケモン」の中の **「個体値チェッカーから取り込む」** を開いて、次の順にやります。

1. [個体値チェッカー](https://nitoyon.github.io/pokesleep-tool/iv/)
   （nitoyon さんの「個体値計算機 for ポケモンスリープ」）を開く
   ※これを元にした改変版でも、同じように使えます
2. 下のタブから **ボックス** を選ぶ
3. 右上の **…**（三点）→ **エクスポート** を押す
4. 形式は **CSV**（TSVでも可）のまま **コピー** を押す
5. このツールの枠の中で右クリック →「貼り付け」（または Ctrl+V）
6. **取り込む** を押す

取り込むと、次のものが**全部そのまま**入ります。手で入れるより正確です。

- レベル・食材構成（AAAなど）・メインスキルのレベル
- **せいかく**（おてつだいスピード／食材確率／スキル確率／**げんき回復量**の上がり下がり）
- **サブスキル**（おてつだいスピードS/M、食材確率アップS/M、スキル確率アップS/M、
  おてつだいボーナス、きのみの数S、**げんき回復ボーナス**）
  ※レベルが足りていないものは効かない扱いです
- **寝顔リボン**（進化が残っているポケモンのおてつだいが速くなる）

### 入れた設定はおぼえています

**一度入れた設定は、次に開いたときも残ります。** 毎回入れ直す必要はありません。

おぼえているもの：**フィールドボーナス・なべの大きさ・料理パワーアップの今の分・
いいキャンプチケット・睡眠スコア・計算する日数・イベント倍率・食材の在庫・
ナイトキャップピカチュウの設定・フィールド・今週のカテゴリ**

> **フィールドと今週の料理カテゴリは毎週変わります。**
> これらも前のままになっているので、**週が変わったら選び直してください。**

（料理ごとのレシピレベルと、読み込んだポケモンも、別々におぼえています）

アドレスバーが出ず、電波がないところでも使えます。

**iPhone（Safari）**
1. サイトを開く
2. 下の **共有ボタン**（□に↑）を押す
3. **「ホーム画面に追加」** を選ぶ

**Android（Chrome）**
1. サイトを開く
2. 右上の **︙** を押す
3. **「アプリをインストール」**（または「ホーム画面に追加」）を選ぶ

**パソコン（Chrome / Edge）**
アドレスバーの右に出る **インストールのマーク**（⊕ や画面のマーク）を押します。

ホーム画面では **「編成ナビ」** という名前で出ます。

> **中身を直したときは、開き直せば新しくなります。**
> このアプリは「通信できるときは、かならずインターネットから最新を取ってくる」作りです。
> 電波がないときだけ、とっておいたものを使います。

### 食材の在庫を、ざっくり入れる

「3 今週の料理カテゴリ」→「🧺 いま持っている食材を入れる」の中に
**「だいたいで埋める」** ボタンがあります。

**ぜんぶで600個くらい**になるように入ります。

- 手に入りにくい **ふといながねぎ・おいしいシッポ・ずっしりカボチャ**：**20個ずつ**
- のこりの食材：**34個ずつ**

**0から始める人はほとんどいない**ので、19種類を全部手で入れるのが大変なときは、
まずこれを押してから、分かるものだけ実際の数に直すのがおすすめです。

**在庫があるかどうかで結果は変わります。**（例：シアン・244匹から選んだ場合、
在庫なし 約112万 → だいたいで埋めた場合 約126万）。
貯めた食材があると、その分だけ上位の料理に手が届くようになるためです。

### ポケモンボックス（読み込んだ子は保存されます）

**読み込んだポケモンは、このパソコンに自動で保存されます。**
次に開いたときも残っているので、**毎回スクショを撮り直す必要はありません。**

#### お気に入りと、とくい分野

「6 自分で選んで試す」→「✏️ 読み込んだポケモンを見る・直す」の一覧で使えます。

- 名前の左の **☆** を押すと **★お気に入り**になります。もう一度押すと外れます
- 名前の右に **きのみ／食材／スキル** の札が自動で付きます（ポケモンごとに決まっているので、
  自分で付ける必要はありません）
- **6匹以上**いるときは、上に絞り込みが出ます
  - **ならべ方** に「★お気に入りが先」
  - **とくい分野** で きのみ／食材／スキル だけに絞る
  - **★だけ** のチェック
- ★は**ボックスに一緒に保存**されます。ファイルに書き出したときも残ります

- 「4 手持ちのポケモンを読み込む」に **🎒 ボックスに ○匹 保存中** と出ます
- 開き直すと「前に読み込んだ ○匹 をボックスから戻しました」と表示されます
- **入れ直したいときは「全部けす」**を押してから読み込んでください

※保存先は「そのパソコンのそのブラウザ」です。そのままでは別の端末に引き継がれません。
**別の端末に移したいとき・消えると困るとき**は、次の「ボックスをファイルに保存する」を使ってください。

### ボックスをファイルに保存する（別の端末へ移す・消えたときに備える）

**ページの一番下**（出典が書いてある行のすぐ上）にある
**「💾 ボックスをファイルに保存する」** を開いてください。

保存されるのは、**手で入れたもの2つ**です。

| 入るもの | 入らないもの |
|---|---|
| 読み込んだ**ポケモン**（全部） | フィールド・今週の料理カテゴリ |
| **料理ごとのレシピレベル**（78品ぶん） | 食材の在庫・なべ・キャンプチケットなど |

フィールドや今週のカテゴリは毎週変わるので、わざと入れていません。

**ファイルで移すとき**

1. **⬇ ファイルに書き出す** を押す
2. `pksl-teams-box-20260825.json` のような名前のファイルが**ダウンロードフォルダ**にできる
3. そのファイルを、移したい先のパソコンに持っていく
4. 移した先で **⬆ ファイルから読み込む** を押して、そのファイルを選ぶ

**文字で移すとき（スマホへ移すときはこちらが楽です）**

「**ファイルではなく文字でやりとりする**」を開いてください。

1. **文字にする** を押すと、枠にボックスの中身が文字で出る
2. **コピー** を押して、自分あてのメールや LINE、メモ帳に貼っておく
3. 移した先で、その文字を枠に貼り付けて **貼り付けた文字から読み込む** を押す

※読み込むと、**いま入っているポケモンは全部置きかわります**
（中身が入っているときは、先に「よろしいですか？」と聞かれます）。

### スクリーンショットから読み込む（個体値計算機を使っていない人向け）

「4 手持ちのポケモンを読み込む」の中の
**「スクリーンショットから1匹ずつ読み込む」** を開いてください。

1. ポケモンスリープで、読み込みたいポケモンの**ステータス画面**のスクショを撮る
2. 枠に**ドラッグ＆ドロップ**する（枠を押してファイルを選ぶ、Ctrl+Vで貼り付けもできます）
3. 読み取れたら一覧に追加されます

| 読み取れるもの | 読み取れないもの |
|---|---|
| ポケモン名（ニックネームのときは読めません） | **寝顔リボン**（いったん「なし」） |
| **レベル** | メインスキルのLv（いったんLv6） |
| **食材構成**（AAAなど） | |
| せいかく | |
| サブスキル5枠 | |

**読み取れないものは、追加された行が開いた状態になるので、そこで手で入れてください。**

**レベルについて**：ステータス画面には「Lv.」が5つも写っています（本人のレベル・食材の
解放レベル・サブスキルの解放レベル・メインスキルのレベル）。このツールは
**「Lv.○○ のすぐ後ろにポケモンの名前が来るもの」だけ**を本人のレベルとみなします。
決められなかったときは、まちがった数字を入れずに **50 のまま**にします。
**読み取った数は画面に必ず出る**ので、ちがっていたらその場で直してください。

#### ニックネームを付けている場合

種類が読み取れないので、**ニックネームだけ入れた状態で追加**されます。
行の「ポケモン」欄に種類の名前を入れてください。
**入れた時点で、食材構成も自動で決まります。**

#### 食材構成の決め方

アイコンの絵ではなく、**アイコンの下に出ている「×2」などの数字**から決めています。

数字のほうが確実だからです。アイコンは、ポップアップに隠れていたり、
まだ開放されていなくてグレーになっていたりすると、色で見分けられません。
数字なら、そういう場合でも読めます。

例：バリヤードで「×2 ×4 ×6」と読めたら、
あんみんトマト2 → ポテト4 → ポテト6 と決まるので、構成は **ABB** になります。

#### サブスキルとレベルの関係

サブスキルは Lv.10 / 25 / 50 / 70 / 80 で開放されます。
スクショには**まだ開放されていないもの（グレーの鍵つき）も写っています**が、
このツールは**レベルが届いていないサブスキルは効かせません。**

**レベルを直すと、そのぶんが自動で反映されます。**

※文字を読む部分（Tesseract.js）はインターネットから取ってきます。
　**ネットにつながっている必要があり**、最初の1回だけ少し時間がかかります。
※読み取りの部品は `mytools/vision/`（自作の pokesleep-vision）です。
　組み立てのときに `index.html` の中にまとめて入ります。

### 「使う」のチェックについて（6 の欄だけの話）

**5 の答えには関係ありません。** 6 の「自分で選んで試す」を開いたときだけ使います。
**ポケスリのチームは5匹まで**なので、6 の結果は「使う」にチェックした子だけで計算します。
読み込んだ直後は先頭の5匹にチェックが入っています。

### たくさんいるときの探し方

手持ちが多いと一覧が長くなるので、次のようにしてあります。

- **一覧は1行ずつの小さい表示**。細かく直したいときだけ「**ひらく**」を押す
- **一覧の中だけがスクロール**する（ページ全体が長くならない）
- **名前でさがす**欄がある（「ジバ」と打つとジバコイルだけになる）
- **ならべ方**を「きのみエナジーが高い順」「レベルが高い順」「名前順」に変えられる
- **「使う子だけ」**にチェックを入れると、今のチームだけが残る

行の右側に出る印の意味です。

| 印 | 意味 |
|---|---|
| 🎀 | 寝顔リボンあり |
| 🤝 | おてつだいボーナス持ち |
| 🍲 | 料理パワーアップ持ち（なべを大きくする） |
| ✨ | 料理チャンス持ち（大成功しやすくする） |

### フィールドとEXフィールド

通常の7つに加えて、**ワカクサ本島 EX** と **シアンの砂浜 EX** を選べます。

EXフィールドでは、好みのきのみが「**メイン1つ＋サブ2つ**」に分かれていて、
おてつだいスピードが変わります（出典: pokesleep-tool の PokemonStrength.ts）。

| | メインの好み | サブの好み | 好みでない |
|---|---|---|---|
| ワカクサ本島 EX | 10%速い | 変化なし | 15%遅い |
| シアンの砂浜 EX | **20%速い** | 変化なし | **35%遅い** |

きのみエナジー2倍は、メインもサブも同じようにつきます。
「どれがメインか」は毎週変わるので、画面の欄で選んでください。

**好みのきのみの決まり方は、2つのEXで違います。**

| | メイン | のこりの2つ |
|---|---|---|
| ワカクサ本島 EX | 全タイプからランダム | 全タイプからランダム |
| **シアンの砂浜 EX** | **みず／フェアリー／ひこう の中から** | **全タイプからランダム** |

シアンの砂浜EXでは、画面の「好みのきのみ 1（メイン）」の候補が**この3つだけ**になり、
2つめと3つめは全タイプから選べます。今週のものを選んでください。

**シアンの砂浜EXは、さらに最大所持数（カバン）が全員 +5** されます
（出典: PokemonStrength.ts の `cbexCarryLimitAdd`）。ワカクサ本島EXにはこれがありません。

#### EXの週替わりバフ（必ず選んでください）

EXフィールドでは、**好みのきのみを持つポケモン**に、次のうち**どれか1つ**のバフがかかります。
毎週変わるので、画面の「今週のEXのバフ」で選んでください。

| バフ | 効果（好みのきのみ持ちだけ） |
|---|---|
| きのみ | きのみエナジーの倍率が 2倍 → **2.4倍** |
| 食材 | 食材おてつだいのたびに **+1個**。食材とくい／オールは50%の確率でもう1個（平均+1.5） |
| スキル | メインスキルの発動確率が **1.25倍** |

さらに、バフの種類に関係なく **「メインの好みのきのみ」のポケモンはスキルレベルが+1** されます。

**ここを選ばないと、数字が大きく変わります。**

### フィールドボーナス（必ず入れてください）

フィールドを進めると増える倍率で、**きのみも料理もまとめて増えます**（最大 +100％＝2倍）。
ゲーム内のフィールド選択画面に出ている「エリアボーナス ○％」を入れてください。

**ここが0のままだと、実際よりかなり低い数字が出ます。**

### レシピレベル（料理ごとに入れてください）

**同じ料理を作り続けると上がり、料理のエナジーが増えます。**
Lv1 で +0%、Lv30 で **+61%**、Lv50 で **+142%**、Lv65 で **+234%**、Lv70 で **+258%** です。

**よく作る上位料理だけレベルが高く、作ったことのない料理はLv1のまま**というのがふつうです。
1つの平均で計算すると、**作ったことのない料理を高く見積もってしまいます。**

そこで「3 今週の料理カテゴリ」の中の
**「料理ごとのレシピレベルを入れる」** から、料理ごとに入れられるようにしてあります。

- 分かるぶんだけ入れれば大丈夫です（空欄なら「入れていない料理に使う値」を使います）
- **入れた値はこのパソコンに記憶され、次に開いたときも残ります**
- レベルが上がったら、その料理の数字を書き換えてください
- ふだんは「今週のカテゴリだけ表示」で十分です。全部見たいときはチェックを外します
- 一覧は**エナジーの高い順**なので、上のほう（＝よく育てる料理）から埋めていくと楽です

どれだけ違うか、実際の例です（フィールドボーナス85%）。

| | Lv1のとき | 実際のレベルのとき |
|---|---|---|
| りんごさんヨーグルトサラダ（Lv69） | 35,692 | **125,636** |
| 合計エナジー（同じ手持ち・7日） | 1,241,969 | **2,518,591** |

※記憶は「そのパソコンのそのブラウザ」に保存されます。
　別のパソコンやスマホで開くと、入れ直しになります。

### 料理の大成功

料理は確率で**大成功**します。出典: Wiki*「料理」（2026-08-23 確認）。

| | 大成功の確率 | エナジー倍率 | 平均すると |
|---|---|---|---|
| 月〜土 | 10% | 2倍 | **×1.10** |
| **日曜** | **30%** | **3倍** | **×1.60** |

**料理チャンスS**（ラグラージ・デデンネ・ウッウなど9匹）を持つポケモンを入れると、
大成功率が上がります（スキルLv1〜6で1回あたり +4〜10%、合計 **+70% が上限**）。

**このスキルは、料理パワーアップとは仕組みが違います。** ゲーム内の説明はこうです。

> 効果は**料理が大成功するか、フィールドを移動するまで**続きます。

つまり**ふつうに料理してもリセットされず、貯まっていきます**（大成功したときだけ0に戻る）。
そこでこのツールは、**1食ごとに「いまどれだけ貯まっているか」を追いかけて**計算します。

デデンネ2匹ぶん（1日+97%）で試すと、こうなります。

| | 1食目 | 5食目以降（落ち着いたあと） |
|---|---|---|
| エナジーの倍率 | 1.42倍 | **1.56倍** |

週の平均で **大成功率61%**。実際のプレイヤーの体感（60%くらい）と一致しました。
料理チャンス持ちを外すと大成功率13%まで落ち、**合計エナジーが約25%下がります。**

**日曜は特別**です。基礎の大成功率が30%・3倍なので、貯まっている状態だと
1食で **2.4〜2.5倍**になります。

#### 上限まで貯まると、スキルが発動しなくなります

**+70%（上限）まで貯まると、それ以上はスキルが発動しません。**
（デデンネをタップしても「次の大成功まで発動できません」と出ます）
大成功して0に戻ると、また発動できるようになります。

**チームを入れ替えても、貯まった大成功率そのものは消えません。**
消えるのは、そのポケモンにたまっていた「**発動待ちのスキル**」です。
このツールは、その発動待ちのぶんまでは数えていません。

### 食材ゲットS と プラス・マイナス

**食材ゲットS**（31匹）を持つポケモンは、スキル発動でまとめて食材をもらえます。
ゲーム内の説明は「入手したことのある食材の中から3種類を均等に取得」なので、
このツールでは**19種類に均等にならして**計算しています。

**そのうえで、もらえる数の半分だけを数えています。**
このスキルでもらえるのは**ランダムな3種類**で、そのとき作りたい料理の材料になるとは限らず、
余りやすいためです（実際に遊んでいる人からは「食材が足りないときの穴うめにしか使わない」
という声がありました）。
半分という数字に厳密な根拠はありません。**全部数えると食材ゲット持ちが編成に入り続けてしまい、
実際のプレイ感と合わなかった**ため、こうしています。
なお、種類が決まっている**プラスの追加ぶん（自分の1枠目の食材）には、この割引をかけていません。**

| スキル | Lv1〜7でもらえる数 |
|---|---|
| 食材ゲットS（28匹） | 6 / 8 / 11 / 14 / 17 / 21 / 24 |
| プラス（食材ゲットS）（プラスル・ストリンダー(ハイ)） | 5 / 7 / 9 / 11 / 13 / 16 / 18 |
| プレゼント（食材ゲットS）（デリバード） | 4 / 6 / 8 / 10 / 12 / 15 / 17 |

**プラスとマイナスを両方チームに入れると、追加効果が出ます。**

- **プラス側**（ストリンダー(ハイ)など）… 上に加えて、**自分の1枠目の食材を14個**もらう
  → ストリンダー(ハイ) の1枠目はモーモーミルクなので、ミルクが大量に手に入ります
- **マイナス側**（ストリンダー(ロー)・マイナン）… 料理パワーアップに加えて **げんきエールS も出る**
  （げんきの回復として計算に入っています）

実際に試すと、ストリンダーをハイだけ入れた場合とハイ＋ローを入れた場合で、
6日で集まるモーモーミルクが **563個 → 1391個** に変わりました。

### ナイトキャップピカチュウ（Pokémon GO Plus+）

**チームの5匹とは別に働いてくれる6匹目**です（編成の枠を使いません）。
「4 手持ちのポケモンを読み込む」の中の
**「ナイトキャップピカチュウを使っている」** を開いて、**なつき度**を入れてください。

ふつうのポケモンとは仕組みが違います（出典: Wiki*「PokémonGOPlus+」）。

- レベルの代わりに **なつき度（1〜20）**。きのみエナジーは「なつき度＝レベル」で計算
- **げんきの概念がなく**、表の時間どおりの間隔で働く（なつき度20で59分に1回）
- せいかく・メインスキル・サブスキルなし
- きのみは **ウブのみ**（でんき）。**好みのきのみなら2倍**になる
- 食材は **とくせんリンゴ／リラックスカカオ／あまいミツ**（ミツはなつき度19から）
- **1日1回、ポケストップを回した数**に応じて ウブのみ 6〜14個 をもらえる

なつき度20だと、1日あたり **とくせんリンゴ12個・リラックスカカオ5個・あまいミツ3個**。
Wiki に書かれている数字と**ぴったり一致**することを確認しています。

### げんき と ヒーラー（一番効きます）

**げんきが高いほど、おてつだいが速くなります。**（出典: pokesleep-tool の Energy.ts）

| げんき | おてつだい間隔 |
|---|---|
| 80より上 | **×0.45**（一番速い） |
| 60より上 | ×0.52 |
| 40より上 | ×0.58 |
| それ以下 | ×0.66 |
| 0 | ×1.00 |

- げんきは**起きている間、10分で1%**ずつ減ります
- **睡眠で回復**します（睡眠スコア100＝510分ねむって100%。上限100、げんき回復ボーナス持ちは105）
- **ヒーラーのスキルで回復**します

このツールは、1日を10分きざみで追いかけて、
**げんきの上がり下がりに合わせておてつだい回数を数えています。**

#### 回復させるスキル

| スキル | 回復量（Lv1〜6） | だれが回復するか |
|---|---|---|
| げんきオールS（16匹） | 5 / 7 / 9 / 11 / 15 / 18 | **チーム全員** |
| げんきエールS（9匹） | 12 / 15 / 20 / 25 / 33 / 44 | ランダムに1匹 |
| げんきチャージS（34匹） | 12 / 16 / 21 / 27 / 34 / 43 | 自分だけ |

※マイナス（料理パワーアップS）は、対になる子がいるとげんきエールSも出ます。

#### どれくらい効くか

ライチュウ Lv60・睡眠スコア100で試した結果です。

| 1日の回復量 | おてつだい回数 | げんきの平均 |
|---|---|---|
| 0（ヒーラーなし） | 75.7回/日 | **37%** |
| 60 | 90.9回/日 | 78% |
| 100 | **98.9回/日** | **100%** |

チーム全体で比べると、**ヒーラーを候補から外した場合と比べて合計エナジーが2.4倍**になりました。
あきらさんの言うとおり、**ヒーラーありきの編成**になります。

結果の「1匹ずつの内わけ」に**げんきの平均**が出るので、
60%を切っている（オレンジ色になる）ときは回復が足りていません。

### カバン（最大所持数）と つまみ食い

**ねている間にカバンがいっぱいになると「つまみ食い」**になり、
それ以降は**きのみだけがカビゴンに直接渡され、食材が入らなくなります。**

カバンの上限はこう決まります（出典: pokesleep-tool の PokemonIv.ts）。

```
ポケモンの基本値 ＋ 5×進化回数 ＋ 寝顔リボン ＋ 最大所持数アップ×6
      × いいキャンプチケット1.5倍…ではなく 1.2倍
```

寝顔リボンによる増加は、時間ごとに **+1 / +3 / +6 / +8** です。

結果の「1匹ずつの内わけ」に **つまみ食い** の割合が出ます。
15%を超えるとオレンジ色になるので、そのときは
**最大所持数アップを持つ子に替える**か、**寝顔リボンを進める**と減ります。

実際に試した例です（ライチュウ Lv60・睡眠スコア100）。

| | カバンの上限 | つまみ食い |
|---|---|---|
| そのまま | 31 | 12% |
| 寝顔リボン2000時間 | 39 | 7% |
| 最大所持数アップL | 49 | **0%** |

**ヒーラーで速くなるほど、つまみ食いも増えます**（カバンが早く埋まるため）。
回復なしで12%、回復120だと20%になりました。

チーム全員に最大所持数アップLを付けると、合計エナジーが **9.1%** 増えました。

※**起きている間は、こまめに集めている前提**で計算しています（あふれない扱い）。

### 献立の組み方

このツールは「1週間ずっと同じ料理を作る」とは考えません。
実際のプレイと同じで、**毎食、そのとき作れる中でいちばんエナジーの高いものを作る**
という前提で、21食ぶんの献立を組みます。食材は毎日少しずつ増えていくものとして計算します。

そのため結果は「サラダA×8回、サラダB×7回…」のような**混ざった献立**になります。

### 自動でチームを組む

**5 の欄には、読み込んだポケモン全員の中から
1週間の合計エナジー（きのみ＋料理）がいちばん大きくなる組み合わせ**が自動で出ます。
ボタンを押す必要はありません。設定を変えると、そのつど計算し直します。

**途中の入れ替えも組みます。** 「1日目〜3日目はピクシー、4日目はカメックス」のように、
何日目に誰を入れるかまで表で出ます。緑色の子は「なべを育てる子（料理パワーアップ持ち）」で、
なべを先に大きくするため早い日に入れています。

**「1日目の編成を、下の『自分で選んで試す』に写す」** を押すと、
6 の欄でその5匹の細かい内わけを見られます。

#### 「なぜこの料理か」も出ます

一番エナジーを稼ぐ料理について、**どの食材を誰が出しているか**を表で出します。

> **なぜ「とびはねるカレーうどん」なのか**
> あったかジンジャーをボーマンダ（ABB）、あじわいキノコをクワガノン（ABB）が出すので、
> このメンバーで作りやすい料理です。
>
> | 必要な食材 | 1回 | 6回ぶん | 集まる量 | 誰が出すか |
> |---|---|---|---|---|
> | あったかジンジャー | 39 | 234 | 251 | ボーマンダ（ABB） 252 |
> | あじわいキノコ | 31 | 186 | 499 | クワガノン（ABB） 354 ／ ゲンガー（ABB） 146 |
> | げきからハーブ | 22 | 132 | 688 | カイリュー（AAA） 660 |
> | マメミート | 20 | 120 | 252 | アーボック（AAA） 252 |

**集まる量が足りない食材は色が変わります。** 「あと何が足りなくてこの料理にできないのか」が
ひと目で分かるようにしてあります。

献立は**合計エナジーが多い順**に並びます（回数が多い順ではありません）。

#### どうやってさがしているか

7日×5枠の並べ方をそのまま全部試すと、天文学的な数になって計算が終わりません。そこで

1. 「**誰を何日入れるか**」を決める問題に置き換える
2. 出発点を3つ（きのみ重視・食材重視・混合）用意する
3. 「1日ぶんを別の子に移すと良くなるか」を、良くならなくなるまで繰り返す
4. 決まった日数から、**なべを育てる子が先に入るように**日割りする

という作り方をしています。**かなり良いところまで出ますが、まれに取りこぼすことがあります。**

手持ち244匹で試して **0.03秒** で終わることと、
固定5匹の総当たり（3003通り）の最高値を**下回らない**ことを確認しています。
このときは入れ替えありのほうが **+2.26%** 良い結果でした。

#### 気をつけること

- おてつだいボーナスは、日ごとではなく**1週間の平均人数**で計算しています
- 料理パワーアップは「次の料理までにたまるぶん」だけがなべに乗ります

### 食材構成（AAA など）の意味

- **A** … そのポケモンの1つ目の食材
- **B** … 2つ目の食材
- **C** … 3つ目の食材

3文字は、左から順に「食材枠1・枠2・枠3」です。
たとえば **AAA のライチュウ** なら3枠とも「とくせんリンゴ」、
**ABB のパーモット** なら「リラックスカカオ・モーモーミルク・モーモーミルク」です。

名前を入れると、すぐ下にその子が持ってくる食材が出るので、そこで確認できます。

## まだできないこと（大事）

出てくる数字は**目安**です。

- 食材を増やすメインスキル（食材ゲットS・食材マグネットSなど）

また、**ミュウとダークライは扱えません。** この2匹は食材の仕組みが特別なためです。

「どの料理を狙うか」を決める参考にはなりますが、
**エナジーの正確な予測ではありません。**

## データの出どころ

- **ポケモンのデータ**（244匹の食材・おてつだい速度など）
  … [nitoyon/pokesleep-tool](https://github.com/nitoyon/pokesleep-tool)（MITライセンス）から読み込み。
  `mytools/source-data.json` に控えを保存してあるので、本家を持っていなくても組み立てられます。
- **レシピ 78品**（カレー25・サラダ26・デザート27）
  … 「ポケモンスリープ攻略・検証 Wiki*」の『料理/レシピの一覧』を
  2026-08-22 にブラウザで読み取ったもの。`build.py` の中に直接書いてあります。
- **フィールドごとの好みのきのみ** … ポケらく（2026-08-22 時点）
- **なべの容量と計算式** … Wiki*「なべ」（2026-08-22 時点）
- **計算式**（おてつだい間隔・食材確率・スキル発動率・きのみエナジー）
  … pokesleep-tool の `PokemonRp.ts` `PokemonIv.ts` `Berry.ts` `MainSkill.ts` に合わせています。

### 1つだけ、Wiki と合わない数字があります

Wiki*「なべ」に載っている「キャンプチケットあり」の対応表 23個と、
このツールの計算（容量×1.5 を四捨五入）を突き合わせたところ、**22個は一致**しましたが、
**なべ容量 31 のときだけ** Wiki が「45」となっていました。
31×1.5＝46.5 なので、計算上は **47** になるはずです。

前後の行（29→44、33→50）は計算どおりなので、**Wiki 側の誤記の可能性が高い**と考え、
このツールは計算式のほう（47）を採用しています。
なべ容量が31のときだけ影響しますが、いまの容量が31より大きければ関係ありません。

Ver.3.7.0 時点のデータです。

### 検算のしくみ

`build.py` は、レシピの食材の個数を足した数が、Wiki の「計」の列と
1品でも合わなければ**エラーで止まります**。食材の名前も、
ポケモンのデータ側にある19種類と照らし合わせています。

※ Wiki のページを要約ツールで読ませたときは、存在しない料理が混ざったり
数字が別の料理のものになったりしました。**必ずブラウザで表を直接読むこと。**
